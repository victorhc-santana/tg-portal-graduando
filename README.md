# 🎓 App de Centralização e Apoio ao Ingresso Acadêmico (TG - Fatec ZL)

Projeto desenvolvido como Trabalho de Graduação (TG) do curso de Análise e Desenvolvimento de Sistemas da Fatec Zona Leste.

## 📌 Sobre o Projeto
O aplicativo busca solucionar a descentralização de informações acadêmicas, oferecendo ferramentas de organização para ingressantes e estudantes de graduação.
